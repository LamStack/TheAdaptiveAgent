Adaptive Rollout Console

Two agents run the identical staged rollout plan against the identical event stream, computed on the server by the actual adaptive_agent.py engine over a JSON API, not a browser re-implementation. The static agent executes on schedule and never looks up; the adaptive agent checks its assumptions on every observation and only revises the plan when one of them actually breaks.
